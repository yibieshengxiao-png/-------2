# 冠之今天吃什么 🍳

冰箱食谱生成器——输入冰箱里现有的食材，一键生成多套食谱方案。

## 使用方法

### 1. 安装 Python（如已安装可跳过）
- 从 [python.org](https://www.python.org/downloads/) 下载安装 Python 3.8+
- 安装时勾选 "Add Python to PATH"

### 2. 安装依赖
打开命令行（cmd 或 PowerShell），进入本文件夹：
```
pip install flask
```
如果提示 pip 不存在，用：
```
python -m pip install flask
```

### 3. 启动程序
```
python app.py
```

### 4. 打开浏览器
在浏览器地址栏输入：
```
http://127.0.0.1:5000
```

### 5. 使用
- 🧊 **冰箱Tab**：点击食材选择你冰箱里的存货，设置克重
- 🍽️ **食谱Tab**：点击"生成食谱"后自动跳转，查看所有推荐方案
- 👤 **我的Tab**：收藏食谱、历史记录、偏好设置

### 关闭程序
在命令行按 `Ctrl + C`

## 功能特色
- 🥬 60+ 种食材，按蔬菜/肉蛋/豆制品/主食分类
- 🍳 100+ 道家常菜食谱，覆盖猪肉/鸡肉/鸡蛋/牛肉/鱼虾/豆腐/蔬菜/汤品/主食
- 🟢🟡🔴 三色提示：绿=可直接做，黄=食材不够，红=缺食材
- 🔥 营养标签：热量/盐量/健康指数/减肥适配
- ❤️ 收藏食谱、📜 历史记录、⚙️ 偏好设置
- 📱 手机和电脑浏览器均可使用
- 🔌 完全离线可用，无需网络

## 文件说明
- `app.py` - 主程序（Python Flask）
- `data_ingredients.py` - 食材数据库
- `data_recipes.py` - 食谱数据库（100+道菜）
- `templates/index.html` - 前端界面
- `requirements.txt` - Python 依赖
